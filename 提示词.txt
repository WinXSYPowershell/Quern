你要建立完整的生命周期。
你写的代码要易拆分。
你写的代码大部分都可以使用Config.yaml配置
你写的注释是中文。
你写的注释不会啰嗦。
你会不自觉的统一缩进美观。

【实现的函数】：
Run：运行
Output：脚本输出，包含Stderr!宏和Stdwarn!宏和Stdinfo宏，err为红色，warn为黄色，info为蓝色，在输出时同时生成Trace ID和日志。

【维护的堆栈】：
Var池、Dict字典和List字典，在Quern_Poll子进程里面运行。
解释程序也在Quern_Interpreter子进程里面运行。

【代码关键字】
Function函数，最基础的，只能运行里面的代码。（语法糖fn、Fun）：
Function "名称"(参数){
    代码...
}

有Loop循环。（语法糖lp、Lop）：
Loop (次数){
    代码...
}

有If/Else，还有语法糖：Else If、Else Cycle、Else If Cycle、If Cycle。（Else语法糖Els）
If(条件){
    满足条件运行的代码...
Else:
    如果条件不满足运行的代码...
}

有Entrust委托，可以判断条件是否成立，如果成立即运行。（语法糖：entr、Ent）
Entrust(条件){
    满足条件后运行的代码...
}

有Method方法，相当于能传入参数的Fn。（语法糖meth、Metd）：
Mathod "名称"(变量, 变量...){
    代码...务必要用到传入的变量。
}

有Class类，相当于作为模板Fn，仅能定义变量、列表、字典。（语法糖：Cls）：
Class "名称"{
    代码...只能定义变量、列表、字典
}

有Catch的捕获。（语法糖：Cth、Ctch）：
Function "Main"(MainFunction){
    代码...
Catch (error):
    代码...
}


【代码语句】：
变量：
Data.Var 类型 名称 = 内容：定义一个变量
Data.Var 名称 = 内容：更新变量
Data.Var.Delete 名称：删除一个变量
支持的运算符有：+加，-减，*乘，/除，//取整除，%取余
语法糖：+=就是名称 +，-=就是名称 -，*=就是名称 *，/=就是名称 /，//=就是名称 //，%=就是名称 %

列表：
DataStruct.List "列表名" = [项1, 项2...]：定义列表（语法糖：ls、Lst）
DataStruct.List "列表名" = [
    项1,
    项2...
]：同上

字典：
DataStruct.Dict "字典名" = [Key = 项1, Key = 项2...]：定义字典（语法糖：Dct）
DataStruct.Dict "字典名" = [Key = 项1,
    Key = 项2...
]：同上

打印：
Console.Info("字符串")
Console.Info(变量)
Console.Info(L"列表名"序号)
Console.Info(D"字典名"Key)
还有：
Console.InfoColour(16进制颜色, 内容)



别名：
Alias "别名名" = "内容"
使用别名直接输入别名名即可

【访问控制】：
使用Use "函数名"使用函数
使用Private保护函数（Function "函数名"(Private){}），被保护后不能被任何函数访问。
使用Public公开函数（Function "函数名"(Public){}），被公开后所有函数都可访问。
不加入任何访问修饰符就默认只能在当前作用域中使用。
变量：
使用Private保护函数（Private Var 类型 名称 = 内容），被保护后不能被任何函数访问。
使用Public公开函数（Public Var 类型 名称 = 内容），被公开后所有函数都可访问。
不加入任何访问修饰符就默认只能在当前作用域中使用。

【导入】：
使用Import "文件名.q"导入文件，复制文件内容到主文件保存到内存中，然后运行。（语法糖Ipt、Impt）

【主函数】：
每个代码强制需要主函数，解释器只运行主函数里面的内容，主函数使用的参数是MainFunction或者MainFn

【模板】：
使用Class定义一个类之后，在函数中加入Template"类名"使用此模板，将创建一模一样的变量、列表、字典。
